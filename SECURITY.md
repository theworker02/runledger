# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| 1.00 (`1.0.0`) on `main` | Yes |

## Reporting a vulnerability

Do not open a public issue for an undisclosed vulnerability.

1. Open a private GitHub security advisory on [theworker02/runledger](https://github.com/theworker02/runledger).
2. Include reproduction steps, expected vs actual behavior, and impact.
3. We will acknowledge the report and work a fix on `main`.

This tool is a local CLI. It should not handle secrets. Do not paste credentials into issues or sample files.
