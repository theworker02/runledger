runledger

Append-only JSONL command receipts with validation, filtering, summaries, and a structured API.

1.2.0JSRMITNode.js ≥ 18

Overview

RunLedger preserves a durable command history alongside a project. Version 1.2.0 adds receipt shape validation, in-memory filtering, package metadata, stronger declarations, and richer generated JSR documentation.

Structured API

Canonical package: @theworker02/runledger

import { record, summary, isReceipt, PACKAGE } from "@theworker02/runledger";

record("node --test", 0);
console.log(summary());
console.log(isReceipt({ ts: new Date().toISOString(), cmd: "build", code: 0 }));
console.log(PACKAGE.version);

CLI from source

git clone https://github.com/theworker02/runledger.git
cd runledger
node src/cli.js record "node --test" 0
node src/cli.js summary
