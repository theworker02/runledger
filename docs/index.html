runledger

Append {ts,cmd,code} receipts to .runledger.jsonl and list them later.

1.00 / 1.0.0 branch main MIT Node.js >= 18

Overview

Shell history is noisy and easy to lose. runledger writes an append-only JSONL log next to the project so you can prove what ran and whether it succeeded.

Anyone wrapping scripts, workshop graders, or local CI helpers who need a durable, grep-friendly command log.

Install

Install globally from Git, or run with Node from a clone. There are no extra dependencies.

npm install -g git+https://github.com/theworker02/runledger.git
runledger --help
node src/cli.js --help

Usage

Synopsis: runledger <command> [args]

See the full CLI reference for every flag, exit code, and example.

runledger 1.00 (1.0.0)

Usage:
  runledger record <cmd> <code>
  runledger list
  runledger --help
  runledger --version

Append JSONL receipts {ts,cmd,code} to ./.runledger.jsonl.

Subcommands:
  record   Append one receipt. <cmd> is a string; <code> is an integer exit code.
  list     Print every receipt as pretty JSON.

Options:
  -h, --help       Show this help
  -v, --version    Print 1.0.0

Examples:
  runledger record "npm test" 0
  runledger record "npm lint" 1
  runledger list

Examples

Success

Record a passing command, then list.

runledger record "npm test" 0
runledger list
[{"ts":"2026-08-23T16:00:00.000Z","cmd":"npm test","code":0}]

Failure

Missing arguments fail fast.

runledger record
usage: runledger record <cmd> <code>

Exit code is 1.
