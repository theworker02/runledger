runledger

Every flag, subcommand, and exit code. Same examples as the README.

Synopsis

runledger <command> [args]
Tip: runledger --help prints this text in the terminal. runledger --version prints 1.0.0.

Flags and arguments

Flag / argumentMeaning
-h, --helpPrint detailed usage and exit 0.
-v, --versionPrint 1.0.0 and exit 0.
record <cmd> <code>Append one receipt. <cmd> is a string; <code> is the numeric exit code.
listPrint all receipts as a JSON array.

Exit codes

CodeMeaning
0record or list succeeded.
1Unknown subcommand or missing record arguments.

Configuration

Store file is always .runledger.jsonl in the current working directory. There is no global config. Create the file by recording; missing file means list returns [].

Worked examples

Success path

Record a passing command, then list.

runledger record "npm test" 0
runledger list
[{"ts":"2026-08-23T16:00:00.000Z","cmd":"npm test","code":0}]

Failure path

Missing arguments fail fast.

runledger record
usage: runledger record <cmd> <code>

Exit code is 1.
